Figma, Inc.(FIG-1.98%)reported financial results for the second quarter of 2026, achieving its third consecutive quarter of accelerated revenue growth. Management reported that the transition to a full-stack creation canvas, which integrates code, agents, and expressive design capabilities, is driving increased engagement among both designers and engineers.   [ 37] [EN] MCP (Model Context Protocol): An open standard for connecting AI agents to external data sources and tools, used by Figma to integrate design and code workflows.
       [中] MCP（Model Context Protocol，模型上下文协议）：一种用于将AI代理连接至外部数据源和工具的开放标准，Figma使用该协议来集成设计与代码工作流程。

---

MCP (Model Context Protocol): An open standard for connecting AI agents to external data sources and tools, used by Figma to integrate design and code workflows.

  [ 38] [EN] Code Layers: A Figma feature that allows interactive code to live directly on the design canvas for visual and code-based editing.
       [中] Code Layers：Figma的一项功能，允许交互式代码直接存在于设计画布上，以便进行基于视觉和代码的编辑。

Code Layers: A Figma feature that allows interactive code to live directly on the design canvas for visual and code-based editing.

  [ 39] [EN] Shaders: AI-powered tools within Figma that generate and manipulate complex textures and visual effects like liquid glass.
       [中] Shaders：Figma中由AI驱动的工具，可生成和操控复杂纹理和视觉效果，如液态玻璃。

Shaders: AI-powered tools within Figma that generate and manipulate complex textures and visual effects like liquid glass.

  [ 40] [EN] Figma Weave: An AI tool for media generation and editing that allows users to sculpt and refine visual assets directly on the canvas.
       [中] Figma Weave：一款用于媒体生成与编辑的AI工具，允许用户直接在画布上雕琢并精修视觉资产。

Figma Weave: An AI tool for media generation and editing that allows users to sculpt and refine visual assets directly on the canvas.

  [ 41] [EN] Figma Make: An AI tool used to generate functional prototypes and production-ready code from design prompts.
       [中] Figma Make：一款人工智能工具，可根据设计提示生成可运行原型和可直接用于生产的代码。

Figma Make: An AI tool used to generate functional prototypes and production-ready code from design prompts.

  [ 42] [EN] Inference: The process by which a trained AI model processes input data to generate a response or output.
       [中] 推理：经过训练的AI模型处理输入数据以生成响应或输出的过程。

Inference: The process by which a trained AI model processes input data to generate a response or output.

  [ 43] [EN] Config: Figma's annual user conference for designers, developers, and product teams.
       [中] Figma面向设计师、开发者和产品团队的年度用户大会。

Config: Figma's annual user conference for designers, developers, and product teams.

ARR (Annual Recurring Revenue): The annualized value of active customer agreements, assuming existing terms for renewals.
