INDUSTRY GLOSSARY

MCP (Model Context Protocol): An open standard for connecting AI agents to external data sources and tools, used by Figma to integrate design and code workflows.

Code Layers: A Figma feature that allows interactive code to live directly on the design canvas for visual and code-based editing.

Shaders: AI-powered tools within Figma that generate and manipulate complex textures and visual effects like liquid glass.

Figma Weave: An AI tool for media generation and editing that allows users to sculpt and refine visual assets directly on the canvas.

Figma Make: An AI tool used to generate functional prototypes and production-ready code from design prompts.

Inference: The process by which a trained AI model processes input data to generate a response or output.

Config: Figma's annual user conference for designers, developers, and product teams.

ARR (Annual Recurring Revenue): The annualized value of active customer agreements, assuming existing terms for renewals.

10-Q: A quarterly financial report required by the SEC that provides a comprehensive view of a company's performance.

GAAP (Generally Accepted Accounting Principles): The standard framework of guidelines for financial accounting.
